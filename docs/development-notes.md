# 開発の記録

photo2stampを作る過程で試したこと、採用した理由、やめた理由をまとめた記録です。
同じ失敗を繰り返さないよう、設定を変える前にここを読んでください。
各段階のコミットは表の左端に載せています。`git show <コミット>`で当時のコードを見られます。

## 目標

写真を、少ない色数で平らに塗ったスタンプ風のイラストにすること。
写真に忠実である必要はなく、何が写っているかが分かれば十分です。
画像生成AIは使わず、CPUだけで1枚を数秒以内に処理する、という条件も置きました。

## やめたこと(元に戻さないこと)

### 固定パレットを既定にする

`teal`などの固定パレットは、色を明るさの順に割り当てます。
そのため青空が白に、木が黄色になり、物の色が入れ替わります。
1d349e7の段階では、8枚中5枚で被写体が分かりませんでした。
被写体を見分ける手がかりは色相なので、既定は写真の色相を残す`natural`にしています。
固定パレットは選べる配色として残しました。

### 作業画像を極端に小さくする

作業画像を220〜80pxまで縮め、色数も6〜4色に減らすと、建物どうしが溶けて1つの塊になりました。
抽象化は縮小ではなく、L0平滑化と輪郭線で出しています。今の作業画像は500〜400pxです。
色数を写真に応じて自動で減らす処理も、見分けにくくなったので外しました。

### XDoG(τ<1)

XDoGは暗い面全体を黒く塗るので、夜景が黒い塊になりました。
τ=1の素のDoGにして、暗い面の上には線を描かないようにしています。

### 夜景に輪郭線を描く

暗い写真で輪郭線を拾うと、迷路のような線だらけになりました。
夜景では、窓や街灯の明るい点を灯り色の丸で描きます。
夜かどうかは、写真の明るさの中央値が45未満かどうかで判定します。

### スーパーピクセル(scikit-image)

SLICで面を分ける試作は、k-meansより良くならなかったので採用しませんでした(18ce629で依存を削除)。

### 遠景シルエットを`natural`で使う

`natural`では写真の色相が残るので、遠景を1色にまとめても海の上に余計な面が増えるだけでした。
遠景シルエットは固定パレットのときだけ働きます。

## 色の決め方で分かったこと

`natural`配色(`palette.natural_colors`)は、指摘を受けて2回直しました。両方の失敗を踏まえて、今の形になっています。

1回目は、色を鮮やかにしようとして、暗い色の彩度を落とす処理や灰色の判定の境目を強めすぎました。
その結果、彩度が全体に下がりました。
さらに明るい色はsRGBの範囲から外れ、淡い色に切り詰められていたのです。
色のある面の明るさを78までに抑えたのはこのためです。

2回目は逆に、うっすら色がかった面まで一律に彩度40や64に引き上げていました。
写真で灰色にうっすら乗っている色は、物の色より光の色であることが多いです。
日陰は空の青を受け、曇り空やガラスも青みを帯びます。
それを4倍に強めたため、ガラスのビルや日陰の葉が濃い青で塗られていました。

今の規則は次のとおりです。数値は`palette.py`の定数です。

| 項目 | 値 | 理由 |
|---|---|---|
| 彩度 | 写真の彩度から6を引いて3.5倍、上限64、12刻み | 6以下の色味は光やホワイトバランスの揺れとみなして灰色にする。海(彩度11前後)は色として残す |
| 暗い面 | 明るさ5〜25で彩度を30%まで落とす(夜は10〜50で15%まで) | 暗い面の色相は当てにならない。夜空が赤茶色になるのも防ぐ |
| 色相 | 8方向に寄せる。彩度20未満では黄色(88°)の代わりに黄緑(115°) | 針葉樹の森は測ると94°で、黄色に寄せるとからし色になった。本物の黄色(看板)は彩度が高い |
| sRGBの範囲 | 外れたら色相を保ったまま彩度を下げる。写真で彩度35以上の色は、明るさを最大12下げて彩度を保ってもよい | 切り詰めると明るい空が水色に変わった。空まで暗くすると濃すぎる青になった |
| 明るさ | 34〜95を半分は写真どおり、半分は面積で均して割り振り、6刻み。色のある面は78まで | 暗い写真でも明暗の幅を使う。輪郭線が見える明るさを保つ |

鮮やかさは、出力のLab彩度の平均で測ってきました。`natural`の最終版の値は次のとおりです。

| 写真 | 平均彩度 |
|---|---|
| 街の俯瞰 | 16.7 |
| 合成画像 | 13.3 |
| 夕景の橋 | 14.3 |
| 城 | 27.6 |
| 夜景 | 15.0 |
| 灯台 | 18.9 |
| 木陰の道 | 17.2 |
| 寺院 | 10.7 |

## 見分けられるかの確認

出力を1枚ずつ元写真と並べ、何が写っているか分かるかを目で確かめました(枠なし、既定の設定)。
縮小した一覧だけで判断すると見落とすので、等倍で見ています。

| 写真 | 判定 | 見た目 |
|---|---|---|
| 城 | 分かる | 白い壁、青い屋根、尖塔、湖、森 |
| 灯台 | 分かる | 空、海、堤防、白い灯台と赤い先端 |
| 合成画像 | 分かる | ビル、看板、緑の木、道 |
| 街の俯瞰 | 分かる | 輪郭線の入った高層ビル群と空 |
| 夜景 | 分かる | 暗いビル群に灯りの点が並ぶ |
| 木陰の道 | 分かる | 青空、枝、道、緑の葉と日陰の暗い葉 |
| 夕景の橋 | ほぼ分かる | 灯りの付いた橋の帯、川、夕焼け。橋脚のアーチは出ない |
| 寺院 | ほぼ分かる | 段になった塔の形。極彩色の彫刻は灰色と青の面になる |

## 残っている課題

次の課題は未解決です。

- 多色の模様(寺院の彫刻など)は、色が平均されて灰色や青の面になる
- 夜モードの判定は写真全体の明るさだけで行う。半分だけ暗い写真は昼の描き方になる
- 正方形の切り抜き位置は「エッジが最も多い範囲」で決めるので、主役が外れることがある
- 雲の縁も輪郭線として描かれる
- 日陰の葉は暗い灰色になり、写真より緑が少なく見える
